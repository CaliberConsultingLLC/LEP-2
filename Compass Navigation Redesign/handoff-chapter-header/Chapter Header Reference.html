Reading this file

  • Class names here are for the reference only — ship the header as ChapterHeader.jsx with MUI sx and existing tokens.
  • Bar 1 is 60px, bar 2 is 78px, the porthole is 100px at left:28px; top:-38px, and the rail reserves padding-left:152px for it.
  • The drawer grid shares the rail's 152px left inset so purpose text lines up under the chapter name.
  • The drawer has no buttons. The map card is the only clickable element besides closing.
  • Column 2 is scoped to the ACTIVE STEP and written as short fragments — it changes when the selected tab changes. No time estimates.
  • Copy comes from chapterMap.js: chapter.purpose for column 1, step.whatHappens for column 2.
